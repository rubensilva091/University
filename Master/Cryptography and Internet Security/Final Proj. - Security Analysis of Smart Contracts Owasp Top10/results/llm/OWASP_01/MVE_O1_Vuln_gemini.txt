### Security Vulnerabilities Report

1.  **Vulnerability type:** Access Control (Unauthorized `setTreasury`)
    *   **Severity:** Critical
    *   **Affected function and line number(s):** `setTreasury` (line 19)
    *   **Brief description of the risk:** The `setTreasury` function lacks any access control. This means any external address can call this function and change the `treasury` address to an address of their choosing (e.g., an attacker's address). This sets the stage for a complete fund drain.
    *   **Recommended fix:** Implement an `onlyOwner` modifier or similar access control mechanism to restrict this function to only the contract owner.
        ```solidity
        // Add a modifier:
        // modifier onlyOwner() {
        //     require(msg.sender == owner, "Not owner");
        //     _;
        // }
        // function setTreasury(address payable newTreasury) external onlyOwner {
        //     treasury = newTreasury;
        // }
        ```

2.  **Vulnerability type:** Access Control / Unauthorized Fund Withdrawal (Combined with `setTreasury`)
    *   **Severity:** Critical
    *   **Affected function and line number(s):** `emergencyWithdraw` (lines 23-26)
    *   **Brief description of the risk:** The `emergencyWithdraw` function also lacks access control, allowing *any* external user to call it. When combined with the vulnerability in `setTreasury`, an attacker can first call `setTreasury` to set a malicious address as the `treasury`, and then immediately call `emergencyWithdraw` to transfer *all* Ether held by the contract to their controlled address. This leads to a complete and irreversible loss of all deposited funds.
    *   **Recommended fix:** Implement an `onlyOwner` modifier to restrict access to the `emergencyWithdraw` function, ensuring only the contract owner can trigger this critical operation.
        ```solidity
        // function emergencyWithdraw() external onlyOwner {
        //     (bool ok, ) = treasury.call{value: address(this).balance}("");
        //     require(ok, "transfer failed");
        // }
        ```
