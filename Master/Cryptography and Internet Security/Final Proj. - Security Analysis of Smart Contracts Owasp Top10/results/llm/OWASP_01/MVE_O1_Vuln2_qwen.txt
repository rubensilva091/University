1. **Vulnerability Type**: Improper Access Control (Use of `tx.origin`)  
   **Severity**: Critical  
   **Affected Function**: `withdraw` (lines 13-19)  
   **Description**: The contract uses `tx.origin == owner` for access control, which is insecure. An attacker can create a malicious contract that tricks the owner into initiating a transaction (e.g., via phishing). The `tx.origin` will still be the owner's address, but the immediate caller (`msg.sender`) will be the attacker's contract, bypassing access restrictions.  
   **Recommended Fix**: Replace `tx.origin == owner` with `msg.sender == owner` and use a standard access control modifier (e.g., `require(msg.sender == owner)`).
