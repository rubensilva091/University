# Security Policy

## Supported Versions

This is an academic project developed for the Software Security Engineering course. Currently, only the latest commit on the `main` branch is actively supported and evaluated for security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Security is a core focus of this project. If you discover a security vulnerability, please do **not** open a public issue.

Instead, please report it privately via email:
**pg57900@alunos.uminho.pt**

### What to include in your report:
* A detailed description of the vulnerability.
* Step-by-step instructions to reproduce the issue.
* The potential security impact.

I will acknowledge the receipt of your vulnerability report within 48 hours and strive to address the issue promptly. Thank you for helping keep this project secure!
